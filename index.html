平台登录状态

方式一：装商店插件（推荐，一键搞定）

  1. 点右上角「装插件」→ 打开 Chrome 应用商店
  2. 点「添加至 Chrome」→ 确认，几秒装好
  3. 打开要下载的网站（确认已登录）→ 点工具栏的插件图标 → Export 导出
  4. 回到本页点「导入文件」，选中刚下载的文件

插件地址（手动打开也行）： Get cookies.txt LOCALLY

Edge 用户：Edge 加载项商店搜 cookies.txt， 或在 Edge 里直接打开上面的 Chrome 商店链接（需允许其他商店）。

多个平台就逐个导出、逐个导入，会合并，不会互相覆盖。

cookies.txt 等于你的登录凭证：别发给别人，别传到网盘。想撤销授权，点「移除」即可。
